# Fluxo de prospecção

1. Preparar ou obter logo, fotos e assets.
2. Hospedar assets finais no Cloudinary quando houver material real.
3. Criar uma configuração a partir de `src/prospects/configs/modelo.ts`.
4. Trocar textos, cidade, serviços, WhatsApp e identidade.
5. Validar com `npm run prospect:validate`.
6. Abrir a rota `/<slug>`.
7. Revisar mobile e desktop.
8. Enviar a demonstração ao lead.

Não é necessário editar componentes React para cadastrar um novo prospect.
